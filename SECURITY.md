# Política de Segurança (Security Policy)

## Visão Geral
Como entusiasta e praticante de **DevSecOps**, a segurança da informação, a proteção de dados e a garantia de qualidade de código são prioridades em todos os repositórios mantidos por **Marco Júnior**.

## Versões Suportadas

| Versão | Suportado          |
| ------ | ------------------ |
| 1.0.x  | :white_check_mark: |
| < 1.0  | :x:                |

## Relatando uma Vulnerabilidade

Se você identificar uma vulnerabilidade de segurança em qualquer repositório deste perfil, siga os passos abaixo para relato responsável:

1. **Não abra uma Issue pública** referente a vulnerabilidades críticas de segurança.
2. Envie os detalhes técnicos da vulnerabilidade com etapas para reprodução.
3. As notificações serão analisadas em até 48 horas úteis para validação e mitigação.

## Práticas de DevSecOps Aplicadas

- **SAST (Static Application Security Testing):** Análise estática automatizada via CodeQL.
- **SCA (Software Composition Analysis):** Verificação automatizada de dependências vulneráveis via Dependabot.
- **Secret Scanning:** Monitoramento contínuo para evitar a exposição acidental de chaves, tokens e credenciais.
